# 💰 口袋理财 · 收益管家

一个**本地优先**的理财 + 记账 + 资产统计 Web 应用：数据保存在本机浏览器，不上传任何信息。
联网时额外支持**基金实时搜索**。

## 文件说明
- `index.html` — 应用本体（双击用浏览器打开）
- `fund-api.iife.min.js` — 基金数据模块（开源项目 fund-api，MIT 协议，数据源为腾讯公开接口）
- `fund-api.LICENSE.txt` — fund-api 许可证与来源说明

## 快速开始
用浏览器打开 `index.html`。顶部有三个页签：**📈 理财 / 🧾 记账 / 🏦 资产**。
基金搜索、刷新净值需要联网；其余功能完全离线可用。

---

## 📈 理财页
- **总览仪表盘**：总资产、总投入、累计收益、今日收益、综合年化
- **四类产品**：银行活期（按日计息）、银行定期（到期付息、按天摊算）、货币基金（余额宝类、每日复利）、基金（净值型）
- **🔍 基金搜索**：输入名称/代码自动填入当前净值；**🔄 一键刷新净值**
- **＋ 追加投入**：基金按平均成本法更新持仓成本
- **🧩 自定义产品**：单利/复利/到期付息三种计息方式
- **每日收益日历**（过去 14 天 + 未来 14 天预估）、**收益曲线**、**资产分布**
- **📊 利率库**：内置 2026-08 常见银行利率 + 货基七日年化，可编辑

## 🧾 记账页
- **多场景适配**：🏠 日常 / ✈️ 旅游 / 💼 差旅 / 👨‍👩‍👧 家庭，每个场景有专属支出分类（如旅游含交通、住宿、门票、纪念品等）
- **完整记账**：支出/收入、分类（可选自定义分类）、金额、日期、账户、备注；支持**编辑、删除**
- **账户管理**：现金、银行卡、微信、支付宝、余额宝 + 自定义账户，支出/收入实时更新账户余额
- **📥 导入账单教程**：记账页顶部常驻提示卡，图文步骤教你从微信/支付宝导出 CSV 并一键导入
- **🎯 月度预算**：设置预算后显示使用进度条 + 剩余金额，超支自动红色提醒
- **🚦 花费限制提醒**：
  - **每日限额**：今日花费超限/接近 80% 自动提醒
  - **分类预算**：餐饮/交通/购物等 11 类分别设月限额，实时进度条，超支变红 + 横幅提醒
  - **提醒横幅**：每日超限、分类超支、总预算超支/接近，统一在记账页顶部汇总显示
- **🔎 场景筛选视图**：记录列表和分类占比可按「全部 / 日常 / 旅游 / 差旅 / 家庭」筛选
- **本月统计**：收入、支出、结余、分类占比条形图
- **🖨️ 打印账单（三种格式）**：
  1. **明细账单** — 逐条流水（日期/类型/分类/账户/备注/金额）+ 收支合计
  2. **分类汇总** — 支出/收入按分类汇总，含占比
  3. **月度报表** — 按月收支统计 + 资产快照
  （点击后进入浏览器打印对话框，可选"另存为 PDF"）
- **⬇️ 导出 CSV**：全部记账记录导出为 Excel/WPS 可打开的 CSV
- **⬆️ 导入微信/支付宝账单**：一键导入微信支付、支付宝导出的 CSV 账单——
  - 自动识别平台（微信 / 支付宝）、自动处理编码（UTF-8 / GBK）
  - 金额清洗（¥、逗号）、退款行自动跳过、关键词自动归类（餐饮/交通/购物等 10+ 类）
  - 按交易单号**去重**，重复导入不会产生重复记录
  - 导入前预览：条数、收支合计、明细，确认后再写入

## 🎯 目标页（攒钱计划）
- **添加目标**：名称、图标、目标金额、目标日期、已存金额、每月计划投入
- **自动计算**：
  - 进度条 + 百分比、已存/目标/还差
  - 距离目标日期剩余月数 → **平均每月需存多少**
  - 填写「每月计划投入」后：判断能否按期达成 + **预计达成日期**
  - 超过目标日期自动提醒
- **💰 投入**：随时记录向目标的投入，达成自动 🎉 庆祝
- **总览**：全部目标的总体进度、已存合计、还差合计、已达成数
- **建议**：先准备 3–6 个月支出的应急金，再规划大额目标

## 🏦 资产页
- **资产统计**：总资产 = 现金/账户余额 + 理财投资 + **固定资产**；可填总负债 → 净资产
- **🏠 固定资产管理**：可添加房产、汽车、贵金属、收藏品、数字资产、股权等，估值计入总资产
- **🏅 多种评级体系**：可切换 5 种呈现方式——
  - **A1–A10 资产段位**（网络流行法：A=Asset 资产，数字=资产位数，如 A7.5=500 万；按净资产量级自动评估，A1 零钱 → A10 十亿顶尖富豪）
  - **S/A/B/C/D**（四级经典评分）
  - **AAA–C**（三等九级信用评级，央行规定主流标准，AAA 最优）
  - **百分制**（0–100 分）
  - **★ 星级**（1–5 星）
- **🖨️ 资产负债表**：一键生成标准报表（资产/负债/净资产 + 账户/理财/固定资产明细 + 本月收支附表），可直接打印或另存为 PDF
- **账户明细**：各账户余额一览
- **🏅 资产等级评估**：四个维度评分（满分 100）：
  - 净资产规模（30 分）
  - 现金健康度（25 分，建议 ≥ 3 个月固定支出）
  - 投资配置（25 分，建议占总资产 20%–60%）
  - 储蓄率（20 分，本月结余/收入）
  - 等级：S ≥ 90 · A ≥ 75 · B ≥ 60 · C ≥ 40 · D < 40，附各维度得分条与改进建议

## 计算规则（均为预估，实际以机构结算为准）
| 类型 | 规则 |
|---|---|
| 活期 | 每日收益 = 本金 × 年利率 ÷ 365（单利） |
| 定期 | 到期收益 = 本金 × 年利率 × 期限(年)；展示按持有天数摊算 |
| 货币基金 | 每日收益 = 当日本金 × 七日年化 ÷ 365，收益次日计入本金（复利） |
| 基金 | 份额 = 本金 ÷ 买入净值；收益 = 份额 × (当前净值 − 买入净值) |
| 自定义 | 按所选计息方式计算 |

## 关于利率与基金数据
- 内置银行利率为 **2026-08 公开参考值**，请以银行实际为准；可在「利率库」手动修改。
- **基金数据**来自腾讯公开接口（经开源项目 [fund-api](https://github.com/zhangxiangliang/fund-api)，MIT 协议），用 JSONP 方式加载，本地 file:// 打开也能用；不保证实时/准确，仅供个人参考。
- 银行理财产品/存款利率暂无前端可直接调用的免费实时 API（相关数据源多为 Python 库或需授权），故以"内置参考值 + 手动编辑"实现。

## 🛠️ 更多实用功能
- **💾 备份 / 恢复**：页脚一键导出全部数据为 JSON（理财/记账/资产/目标/设置），换设备或清缓存前先备份；恢复时覆盖并重新加载
- **🧮 定投/复利模拟器**（理财页）：输入初始本金、每月定投、年化收益率、年限，实时算出 N 年后总资产、总投入、收益与收益率
- **🔔 周期提醒**（记账页）：信用卡还款 / 房贷 / 房租 / 订阅等周期事项，自动倒计时（还有 X 天 / 今天 / 已逾期），一键"已处理"跳到下一周期
- **📈 近 6 个月收支趋势图**（记账页）：收入/支出/结余柱状图，一眼看清消费走势
- **🔍 记录搜索**：按分类 / 备注 / 账户 / 金额即时过滤记账记录（与场景筛选叠加）

## 数据安全
所有数据仅保存在本机浏览器 localStorage（理财、记账、资产配置分别存储）；清除浏览器站点数据即清空。
